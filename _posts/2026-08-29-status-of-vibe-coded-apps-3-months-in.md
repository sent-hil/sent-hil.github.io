Like a lot of developers I started experimenting with Claude Code in late 2025. Since then I have vibe coded a lot of apps for personal use. Given it's been almost 10 months I wanted to see which ones I do still use.

* [mochi-claude-code-gen](https://github.com/sent-hil/mochi-claude-code-gen) - Mochi Flashcard generator with Claude Code.
* [cache-hit](https://github.com/sent-hil/cache-hit) - Superseded by spaced. A spaced repetition application for reviewing coding problems.
* [geometric-art-generator](https://github.com/sent-hil/geometric-art-generator) - A macOS app that uses AI to generate stunning geometric art from simple text descriptions.
* [nee-reads](https://github.com/sent-hil/nee-reads) - A very simple goodreads alternative for my wife, she never used it.
* [agent-sandbox](https://github.com/sent-hil/agent-sandbox) - Manage Git worktrees per feature.
* [saas-ticker](https://github.com/sent-hil/saas-ticker) - Stock ticker to track see if death of Saas is real.
* Fork of [leaf](https://github.com/sent-hil/leaf) - Markdown viewer, forked to change shortcuts 
* Fork of [ghui](https://github.com/sent-hil/ghui) - Superseded by review.nvim. TUI Github PR reviewer.
* [review.nvim](https://github.com/sent-hil/review.nvim) - Neovim library to help do Github and local change reviews
* [wt](https://github.com/sent-hil/wt) - Agent worktree management TUI. Most used.
* [spaced](https://github.com/sent-hil/spaced) - TUI spaced repetition app. 2nd most.
* bookmarks - New. Replacement for pinboard.in.
